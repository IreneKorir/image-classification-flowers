# Flower Image Classification

An image-classification project completed as part of the Udacity AI Programming with Python Nanodegree. The project trains a deep-learning model to classify flower images into categories and then uses the trained model to make predictions on new images.

> This repository is notebook-based. It does not currently contain standalone `train.py`, `predict.py`, or `utils.py` scripts.

## Project Goals

This project demonstrates how to:

- Load and preprocess an image dataset
- Apply data augmentation to training images
- Use transfer learning with a pretrained convolutional neural network
- Train and validate an image classifier with PyTorch
- Save and reload a trained checkpoint
- Predict the most likely flower classes for an input image

## Repository Contents

| File | Description |
|---|---|
| `Part_1_image_classifier_project.ipynb` | Model-development notebook: data loading, preprocessing, model training, validation, and checkpoint creation |
| `Part_2_image_classifier_project.ipynb` | Inference notebook: loading a saved model, processing an image, and displaying top predictions |

## Setup

Clone the repository:

```bash
git clone [https://github.com/IreneKorir/image-classification-flowers.git](https://github.com/IreneKorir/image-classification-flowers.git)
cd image-classification-flowers
```

Create and activate a virtual environment:

```bash
python -m venv .venv
```

macOS/Linux:

```bash
source .venv/bin/activate
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Install the required packages:

```bash
pip install jupyter torch torchvision numpy pillow matplotlib
```

Start Jupyter:

```bash
jupyter notebook
```

## Data Requirement

The notebooks expect the Udacity flower dataset, typically organised in training, validation, and test folders. Download or prepare the dataset before running the notebooks, then update the dataset paths in the notebook cells as needed.

A typical directory structure is:

```text
flowers/
├── train/
├── valid/
└── test/
```

## How to Run

1. Open `Part_1_image_classifier_project.ipynb`.
2. Update the data paths to point to your local flower dataset.
3. Run all cells from top to bottom to train and validate the model.
4. Save the trained checkpoint generated by the notebook.
5. Open `Part_2_image_classifier_project.ipynb`.
6. Update the checkpoint and image paths.
7. Run the notebook to generate top flower-class predictions.

## Limitations

- The notebooks depend on local dataset paths and may need path updates before execution.
- Results can vary due to random initialisation, hardware, package versions, and training settings.
- The dataset and trained model checkpoint are not currently included in this repository.
- This repository uses notebooks rather than reusable command-line scripts.
